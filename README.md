# 🎵 WaveMusic

**WaveMusic** is a responsive, web-based music player built with HTML, CSS, and JavaScript. It features local audio playback, an online music catalogue, search functionality, and category filters in a modern interface.

## 🌐 Live Demo

🎧 **[Listen to WaveMusic](https://emmatron-blip.github.io/CodeAlpha_WaveMusic/)**

## ✨ Features

- 🎧 **Local Music Playback** — Upload and play audio files directly from your device.
- ▶️ **Playback Controls** — Play, pause, skip to the next track, or return to the previous track.
- 🔊 **Volume Control** — Adjust audio volume.
- ⏱️ **Progress Tracking** — Monitor playback progress and seek through local audio.
- 🌐 **Online Music** — Play selected music through YouTube integration.
- 🔍 **Music Search** — Search the online music catalogue by song title or artist.
- 🎼 **Category Filters** — Browse music by category.
- 📱 **Responsive Design** — Designed for mobile devices and desktop screens.
- 🎵 **Media Session Support** — Provides song metadata and playback controls on compatible browsers and devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API
- Media Session API
